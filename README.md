# 🍽️ Foodies-Goodies

A modern and responsive food website built using **HTML & CSS**, designed to showcase delicious Indian meals with an attractive and user-friendly interface.

---

## 🚀 Features

* 🏠 Beautiful homepage with hero section
* 🍕 Services section showcasing food categories
* 🎯 Offers and new food highlights
* 📞 Contact form for user interaction
* 🧭 Navigation bar with smooth layout
* 🎨 Clean and responsive UI design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
